# 2026-07-28 rebuild

## Source audit

The repository had a Vite frontend and long-running Express backend designed for Replit. Evaluation required a run name, a dataset name, a saved dataset or CSV, and registered prompts before work could begin. The model was hardcoded. File storage would not persist safely across Vercel functions.

## Changes

- Replaced the split deployment with a single Next.js app.
- Added visible, default-on capture in the chat playground.
- Added paste/import/reorder flows for test cases.
- Added combinable prompt and model selectors with an explicit completion count.
- Added automatic run naming, persistent run history, a result matrix, and JSON export.
- Added editable prompt and test-set libraries.
- Added private Vercel Blob persistence and Anthropic model discovery.
- Added unit, desktop browser, and mobile browser checks.
